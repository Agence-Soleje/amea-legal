(contact@agencesoleje.com), en six langues.

**Ne pas modifier ces fichiers à la main.** Le texte qui fait foi est en base
(table `legal_documents`). Les pages sont générées par
`scripts/publier-pages-legales.mjs` dans le dépôt de l'app, puis servies par
GitHub Pages depuis la branche `main`. L'historique git garde chaque version
publiée.

Site statique sans script, sans cookie, sans traceur, sans ressource externe.

voir `fonts/OFL-*.txt`) ; icônes Lucide (licence ISC) écrites dans les pages.
